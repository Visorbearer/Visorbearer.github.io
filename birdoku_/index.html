Birdoku is a bird puzzle game built by Mason Maron and inspired by PokeDoku. Species trait data comes from BIRDBASE, but this project is not affiliated with BIRDBASE or its creators in any way. Any errors in gameplay categories may reflect either data limitations or developer implementation choices. This game is still in development and may contain bugs or incomplete features.
